AI BANNER PROMPT for BearBot
=============================

Generate a 1280x400 banner with any image AI (DALL-E, Midjourney, Ideogram,
Leonardo, etc.), save it as assets/banner.png, and update the image line at
the top of README.md to reference it instead of banner.svg.

Wide GitHub repository banner, 1280x400, dark navy background with a subtle

glowing app tiles: a blue chain-link icon, a green picture-frame icon, and a
white text-lines icon. A small friendly blue robot marches alongside. Flat

TIPS
----
- Generate at 1280x400 (GitHub README headers look best at that ratio).
- Image AIs often garble text: if the title comes out wrong, generate the
  artwork WITHOUT text and add the title yourself in Canva / Figma /
  Photopea.
- Save the result as assets/banner.png and change the first image line in
  README.md from assets/banner.svg to assets/banner.png.
